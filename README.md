## 🙋‍♀️ About me

I build AI-driven products, cloud-native applications, data pipelines and automated infrastructure, for technology with a real-world mission. I like the whole journey: training the model, building the app around it, and getting it running reliably in the cloud. So far I've done that in 🇩🇪 Germany, 🇳🇴 Norway, 🇴🇲 Oman and 🇹🇳 Tunisia.

- 🔋 Right now: writing my Master's thesis at **ACCURE Battery Intelligence**, building platform services for battery-storage customers
- 🤖 Most fun recent build: [**ClarityChains**](https://github.com/OnsKoukiPro/ClarityChains), where LLM agents read supplier offers and tell you which one to pick
- 🍯 Weirdest project: a [Kubernetes honeynet](https://github.com/OnsKoukiPro/Honeypot-CK8s) that invites attackers in so I can watch them
- 💬 Ask me about: LLM agents, forecasting, Kubernetes, SDN and 5G networks
- 🗣️ I speak English, French and Arabic
